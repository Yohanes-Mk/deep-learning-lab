# Deep Learning Lab

Coursework and hands-on work from **Neural Network and Deep Learning** (CSCI 441/541),
Fall 2026.

Concepts and techniques in deep learning, exploring both theoretical foundations and
practical applications — neural network models and deep learning methods for
complex real-world problems, with hands-on experience using state-of-the-art tools
and frameworks. Topics span the course include:

- Designing, training, and applying neural networks for data analysis
- Regularization techniques (e.g. dropout) for generalization and overfitting
- Convolutional neural networks (CNNs) for image classification and computer vision
- LSTM networks for speech recognition, machine translation, and time series
- Transformer architectures and large language models

## Structure

```
Syllabus/     Course syllabus and semester schedule
Week 1/
  Code/       Notebooks and implementations
  Assignment/ Submitted coursework
```

Each week's folder holds that week's code and assignment. Course-provided
lecture slides and transcripts are intentionally excluded (see `.gitignore`) —
this repo tracks original work only.
